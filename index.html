Sync across devices

Connect a free Firebase project so your candidates stay synced across your phone, laptop and any device you sign in on. Without this, data is saved only on this device/browser.

How to set this up (Firebase + GitHub + Vercel) ▾
1. Firebase (the sync database — free)
  1. Go to firebase.google.com → Console → Add project.
  2. Inside the project: Build → Firestore Database → Create database → start in test mode.
  3. Build → Authentication → Sign-in method → enable Anonymous.
  4. Project settings → General → scroll to "Your apps" → Add app → Web app. Copy the config values into the fields above and tap Connect.
  5. In Firestore → Rules, set: allow read, write: if request.auth != null; then Publish.
2. GitHub (store this file)
  1. Create a new repository, e.g. candidate-hub.
  2. Upload this HTML file, rename it index.html, commit.
3. Vercel (put it online / add to home screen)
  1. vercel.com → Add New Project → Import the GitHub repo.
  2. Framework preset: Other → Deploy.
  3. Open the live link on every device you want it on, then "Add to Home Screen" for an app-like icon.

All your devices open the same link and Firebase keeps them in sync automatically.
